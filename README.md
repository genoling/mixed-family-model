# mixed-family-model

**独生与多子混合家庭模式的社会意义——基于集合论组合与计算模拟的理论建构**

一个可复现的论文 + 代码仓库：用"场域隶属度"刻画独生（$A$）与多子（$B$）养育场域的五种组合形态，
建立资源—社会化—摩擦三维效用模型 $U = R \cdot S \cdot (1-C)$，并用多主体模拟（ABM）检验混合模式在代际选择下的稳定性。

> 本仓库同时包含论文正文、模拟代码、图与结果数据，目的是让论文中的**每一个数字都能被重跑出来**。

## 目录结构

```

code/      abm.py —— 多主体模拟（唯一依赖：numpy / matplotlib）
figures/   论文图（由 code/abm.py 生成，勿手工修改）

```

## 快速复现

```bash
python -m pip install -r requirements.txt
python code/abm.py --mode all      # 约 6 分钟：基线 + 区制扫描 + 相图 + 共居可行性扫描
```

单独运行：

```bash
python code/abm.py --mode baseline   # 表 1、图 1（5 次重复）
python code/abm.py --mode regime     # 表 2、图 2（家庭外同伴 s_ext 的区制效应）
python code/abm.py --mode phase      # 图 3（β × 摩擦相图）、图 4（λ × s_ext 共居可行性）
```

随机种子由 `P.seed`（默认 `20260930`）与重复编号确定，结果完全可复现。所有参数集中在 `code/abm.py` 的 `@dataclass P` 中。

## 核心结果（详见 `paper/` 与 `results/summary.txt`）

| 结论 | 数据 |
|---|---|
| 混合模式**并未**主导 | 基线稳态：混合 0.221，纯独生 0.693 |
| 决定权在"家庭外同伴能否替代同胞" | $s_{ext}=0$ 时混合 0.45~0.56；$s_{ext}=3$ 时降至 0.12~0.28，纯独生升至 0.62~0.85 |
| 共居**不构成帕累托改进** | 对称收入下独生家庭儿童受损约 6%；模拟中共居占比 ≤ 0.113 |
| 稳定的混合形态是**单向寄养** | 供子（$B\to A$）0.165 > 献子（$A\to B$）0.040 |

## 与初稿的主要差异

本版修正了初稿 7 处可验证的数学错误（其中"独生子女社会化为零"导致 $U_A\equiv0$ 是枢纽性错误），
并把初稿中**尚未运行**的模拟方案替换为真跑的数据。修正后论文的核心结论发生了实质变化。

## 学术伦理说明

本文是**分析性类型学与条件性推演**，不主张把儿童送离原生家庭，也不把儿童视为可配置的资源。
